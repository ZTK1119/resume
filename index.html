Nº003 // REAL CODE & COMPETITION PROJECT

长三角科创省级一等奖课题实战

省级一等奖 (组长) 2024.07 – 2025.01
第六届长三角中学生数据应用创新研究活动（上海、江苏、安徽三省市电教馆联合主办）

基于数据可视化的电子游戏销量趋势分析及科学教育游戏设计应用研究

在该课题中，本人担任小组组长，统筹数据清洗工程、算法调优与成果答辩。面对 16,000+ 条真实销售数据中的缺失与异常，通过构建字典映射推断（`year_inference`）和中位数插补，完成了高质量的数据集清洗；并基于真实结论利用 Ren'Py 引擎自主开发了融合化学离子反应与解析几何的科普游戏原型《想像一朵未来的桃花》。

数据样本规模 16,240+ 条真实销售数据清洗
